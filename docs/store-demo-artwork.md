## Final prompts

Each asset used this complete prompt, substituting the product and background below:

> Create one premium ecommerce demo product mockup. Reference image role: use only the IMPACT shirt wordmark styling seen in this community photo as the brand inspiration, not the people or setting. Product: one {product}. Straight-on neatly styled flat lay on a {background} seamless studio backdrop, entire shirt including sleeves visible with generous margins, subtle natural fabric texture and soft realistic shadows. Square image, single shirt centered, clean consistent catalog composition. Shirt print text exactly "IMPACT". No additional text, no pricing, no coming soon tags (these will be added by the website), no people, no props, no hangers, no watermark. This is a concept mockup, not a real product photograph. Output asset name hint {name}.
